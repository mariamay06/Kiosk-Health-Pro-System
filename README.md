# 🏥 KioskPro – Health Kiosk System

### PD1 Prototype Project

---

## 📌 Project Overview

**KioskPro – Health Kiosk System** is a healthcare kiosk concept designed to provide a convenient way for users to record basic vital signs and view easy-to-understand health information.

The proposed system aims to make basic health monitoring more accessible through a user-friendly kiosk interface. It focuses on collecting selected vital sign measurements, displaying recorded results, and helping users understand their measurements through clear labels and organized information.

KioskPro is designed as a prototype project that demonstrates how technology can support basic health monitoring and improve access to personal health information.

---

## 🎯 Project Objectives

- To provide a convenient platform for recording basic vital signs.
- To display health measurements in a clear and understandable format.
- To simplify access to basic health monitoring information.
- To organize recorded measurements for easier reference.
- To promote awareness of personal health measurements.
- To develop a user-friendly interface for a health kiosk prototype.
- To demonstrate the potential use of digital technology in basic health monitoring.

---

## ⚙️ Key Features

### ❤️ 1. Vital Signs Recording

Provides a proposed interface for recording selected vital signs, such as body temperature, pulse rate, and blood pressure, depending on the available equipment.

### 🌡️ 2. Temperature Monitoring

Allows users to record body temperature using a suitable temperature measurement device.

### 💓 3. Pulse Rate Recording

Supports recording pulse rate in beats per minute (BPM) when a suitable sensor or validated measurement device is available.

### 🩺 4. Blood Pressure Recording

Provides a way to record systolic and diastolic blood pressure readings using a compatible blood pressure monitor.

### 📊 5. Easy-to-Read Results

Organizes recorded measurements into a simple display with measurement names, units, and timestamps.

### 🖥️ 6. User-Friendly Kiosk Interface

Uses a straightforward interface designed to help users navigate the available monitoring options.

### 🗂️ 7. Measurement History

A proposed feature that can store previous readings for later reference when appropriate data storage is implemented.

### 📄 8. Health Summary

Can be expanded to generate a basic summary of recorded measurements for personal reference.

## 🔄 Proposed System Workflow

1. **Start the Kiosk** – The user opens the health kiosk interface.
2. **Select a Measurement** – The user selects the available vital sign measurement.
3. **Collect the Reading** – A compatible device measures the vital sign, or the user enters an existing reading when manual entry is supported.
4. **Record the Result** – The system records the measurement and its unit.
5. **Display the Result** – The kiosk presents the result in a clear, readable format.
6. **Review the Summary** – The user views the available recorded measurements.
7. **Save or Finish** – The system saves the record if storage is enabled, then ends the session.

## 🔐 Privacy and Security

Health measurements are sensitive personal information. Any implemented data storage should use appropriate access controls, limit the collection of personal data, and provide clear information about how records are stored and used.

The prototype should avoid displaying one user's private measurements to another user.

---

## ⚠️ Health and Safety Disclaimer

KioskPro is an educational prototype concept and is not intended to diagnose, treat, or replace professional medical assessment.

The accuracy of recorded measurements depends on the devices used and the measurement procedure. Results should be interpreted in context, and concerning symptoms or measurements should be assessed by a qualified healthcare professional.

The system should not automatically declare a person healthy or unhealthy based solely on a single measurement.
